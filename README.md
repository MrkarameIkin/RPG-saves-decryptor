ОПИСАНИЕ ПРОГРАММЫ
  Программа позволяет выводить размещенные в отдельных файлах сохранения игроков.
  Сохранения (4) размещаются в папке player_saves и содержат никнейм игрока, его уровень, количество золота и локацию, в которой он находится
  При выборе пункта 1) Играть! -> 2) Сохранения будет выведена информация про каждое из 4 сохранений
  Все остальные пункты выбора не имеют своего прямого функционала
